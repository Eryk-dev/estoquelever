## Codebase Patterns
- In `separacao/iniciar/route.ts`, status validation uses `ALLOWED_STATUSES` array at line 74 and transition filter uses `TRANSITION_STATUSES` at line 90. Both must be updated together when adding new allowed statuses.
- When `handleSepararSelecionados` has optional params, all `onClick` refs must use arrow wrappers `() => handleSepararSelecionados()` to avoid TS type mismatch with MouseEventHandler.
- Supabase `.eq()` for single value filter, `.in()` for multiple values — use `.in()` when filtering by an array of statuses.
- OC decisao resolution: compare OC's galpao_id (from siso_ordens_compra) vs pedido's origin galpao_id (from empresa → galpao). Same = 'propria', different = 'transferencia'. Default to 'propria' if no OC linked.
- After concluir/separado, always fire-and-forget: `kickWorker()`, `preCriarAgrupamentosEmLote()`, and `registrarEventos()`.
