8. WMS — Estoque (Schema 4D + Ledger)

Schema 4D: cada posição de estoque é única por (produto, dona, galpão, localização). Toda escrita passa pela RPC wms_inserir_movimentacao com lock pessimista.

8.1 Modelo de dados

8.2 RPC wms_inserir_movimentacao

sequenceDiagram participant Caller as API ou Service participant RPC as wms_inserir_movimentacao participant Stock as siso_estoque participant Ledger as siso_movimentacoes Caller->>RPC: { produto_id, dona, galpao, loc, tipo, qty, origem_tipo, observacoes } RPC->>Stock: SELECT FOR UPDATE (lock pessimista) alt linha não existe RPC->>Stock: INSERT (saldo=0, reservado=0) end RPC->>RPC: valida saldo>=qty se tipo=S RPC->>RPC: valida reservado<=saldo se tipo=R RPC->>Stock: UPDATE saldo+=delta, reservado+=delta_R RPC->>Ledger: INSERT (saldo_anterior, saldo_posterior, reservado_anterior, reservado_posterior, origem_tipo, ...)
